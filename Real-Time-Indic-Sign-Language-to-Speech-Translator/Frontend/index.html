      ✦ Features

      What makes it work.

      ⚡

      Two separate recognizers

      Browser KNN is the fixed five-sign fallback. A current, validated sequence model can use the saved vocabulary; unvalidated candidates are never live recognizers.

      🗣

      Review before interpreting

      Stable predictions appear in an editable ordered sequence. Remove or correct labels before requesting a sentence suggestion.

      ✦

      Optional local sentence aid

      Ollama can suggest an English interpretation on request. Suggestions and recognition corrections are not verified translations.

      🎯

      Save, then train explicitly

      Developer Studio recordings are saved separately. New examples do not change a model until you train, evaluate, and explicitly activate a candidate.

      🧠

      Experimental sequence model

      It predicts one sign from each 30-frame window; stable labels are accumulated over time. This is not a continuous sign-language translation model.

      🌐

      Local-first workflow

      The active recognizer uses the same browser camera stream. Flask supplies sentence controls and current model/vocabulary state; Developer Studio manages model candidates.

      ✦ Vocabulary status

      Labels that evolve.

      Current saved labels, sample counts, and session counts are available in Developer Studio. The demo refreshes active model support from Flask; a saved label is not automatically recognized, and labels are not gesture instructions.

      ✦ About

      Bridging the silence.

      This project offers a five-label browser KNN fallback and an active sequence classifier built from saved 30-frame, 378-feature landmark sequences when a compatible, validated model has been activated. Neither path performs complete continuous ISL translation.

      Stable word predictions can be reviewed before an optional local Ollama sentence request. Original predictions remain visible; model suggestions are not verified meanings.

      How it works

      A clear path from sign to speech.

      Choose the recognizer explicitly, collect stable word predictions, review them, and request a sentence-level interpretation only when ready.

      01

      Webcam input

      Allow camera access and collect examples for the five demo signs.

      02

      Landmark processing

      The active sequence model extracts the same 30-frame, 378-feature landmark contract used by Developer Studio recordings.

      03

      Sign classification

      The active validated sequence model predicts from saved vocabulary; the KNN fallback uses browser-collected examples for five fixed signs.

      04

      Sentence & speech

      The local AI suggestion is optional and editable; the original sequence stays visible and corrections remain suggestions.
