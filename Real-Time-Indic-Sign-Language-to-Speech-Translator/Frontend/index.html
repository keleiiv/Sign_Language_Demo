      02 The system

      Careful signals.
      Useful language.

      A limited-vocabulary research demonstration: each sign is reviewed as a prediction, then connected to an explicit sentence or optional local suggestion.

      01 / RECOGNITION

      Two separate recognizers

      Browser KNN retains five classifier labels, but the translator accepts only Hello from that fallback. A current, validated sequence model can use saved vocabulary; unvalidated candidates are never live recognizers.

      02 / REVIEW

      Review before interpreting

      Stable predictions appear in an editable ordered sequence. Remove or correct labels before requesting a sentence suggestion.

      03 / LANGUAGE

      Optional local sentence aid

      Ollama can suggest an English interpretation on request. Suggestions and recognition corrections are not verified translations.

      04 / DATA

      Save, then train explicitly

      Developer Studio recordings are saved separately. New examples do not change a model until you train, evaluate, and explicitly activate a candidate.

      05 / SEQUENCE

      Experimental sequence model

      It predicts one sign from each 30-frame window; stable labels are accumulated over time. This is not a continuous sign-language translation model.

      06 / LOCAL FIRST

      Local-first workflow

      The active recognizer uses the same browser camera stream. Flask supplies sentence controls and current model/vocabulary state; Developer Studio manages model candidates.

      03 Vocabulary / model

      A vocabulary in motion.

      The active model and vocabulary are read from the local service. Saved labels are not automatically recognized; new examples require explicit training and validation.

      04 How it works

      From gesture to voice.

      A limited-vocabulary pipeline. The system recognizes individual supported signs and maps accepted labels to configured sentences; it does not translate continuous ISL.

      01

      Capture

      Camera frames are collected locally. The selected recognizer uses the browser camera stream.

      02

      Landmark extraction

      The sequence path processes 30 frames into the established 378-feature landmark representation.

      03

      Sign recognition

      Confidence and hand-quality checks filter predictions. Stable individual signs can be reviewed in order.

      04

      Sentence and speech

      Accepted signs use configured sentence mappings. Optional local AI suggestions can be reviewed before speech.
